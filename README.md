# 🔮 Futuristic Scientific Calculator

A sleek, sci-fi aesthetic scientific calculator built with Python. Features a futuristic terminal UI with neon-style colors and comprehensive mathematical operations.

## ✨ Features

### 🧮 Basic Operations
- Addition, Subtraction, Multiplication, Division
- Exponentiation, Modulo, Floor Division

### 📐 Trigonometric Functions
- Sine, Cosine, Tangent
- Arcsine, Arccosine, Arctangent
- Automatic degree/radian conversion

### 📊 Logarithmic & Power Functions
- Natural Logarithm (ln)
- Logarithm Base 10
- Logarithm Base 2
- Square Root, Cube Root
- Power/Exponentiation

### 🌟 Advanced Operations
- Hyperbolic functions (sinh, cosh, tanh)
- Combinations (nCr)
- Permutations (nPr)
- Greatest Common Divisor (GCD)
- Least Common Multiple (LCM)
- Factorial

### 🎆 Constants
- Pi (π)
- Euler's Number (e)

### 🎨 User Interface
- Futuristic sci-fi aesthetic with neon colors
- Beautiful ASCII art borders
- Clear menu organization
- Error handling with helpful messages
- Degree ↔ Radian conversion utilities

## 🚀 Installation

### Requirements
- Python 3.6+
- No external dependencies!

### Setup
```bash
git clone https://github.com/yourusername/futuristic-calculator.git
cd futuristic-calculator
```

## 🎮 Usage

Run the calculator:
```bash
python calculator.py
```

Or make it executable:
```bash
chmod +x calculator.py
./calculator.py
```

### Examples
```
[1] Addition: 5 + 3 = 8
[5] Exponentiation: 2 ** 10 = 1024
[8] Sine: sin(45°) ≈ 0.707
[17] Square Root: √16 = 4
[29] Combination: C(10,5) = 252
```

## 🎨 Terminal Colors

The calculator uses ANSI escape codes for beautiful colors:
- **Cyan**: Headers and prompts
- **Magenta**: Borders and menus
- **Yellow**: Section titles
- **Green**: Results
- **Red**: Warnings and errors
- **Blue**: Descriptions

Works on:
- macOS Terminal
- Linux Terminal
- Windows PowerShell/CMD (with ANSI support enabled)
